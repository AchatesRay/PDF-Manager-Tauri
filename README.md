# PDF Manager

本地 PDF 管理工具，支持扫描版 PDF 的 OCR 识别和全文搜索。基于 Tauri 2.0 + Rust + Svelte 构建。

## 版本

**v1.2.0** - 2026-09-28

## 功能特性

- **文件夹管理** - 创建文件夹分类管理 PDF 文件，支持多级嵌套与自定义存储目录，文件夹旁显示文档数与已识别进度
- **智能识别** - 自动检测 PDF 类型（文字型/扫描型），选择最优处理方式
- **OCR 识别** - 使用 PP-OCRv5 Mobile 模型（默认启用平衡版，同一套模型文件，内存占用约 300MB）识别扫描版 PDF 中的内容，支持中文识别
- **OCR 任务队列** - 任务排队处理、实时进度、可取消；排队中的任务在重启程序后自动续跑
- **全文搜索** - 中文全文搜索，支持内容搜索与文件名搜索，点击结果直接跳转到对应页面
- **搜索预览高亮** - 搜索命中关键字在右侧预览页上以高亮框标出，「上一个/下一个」导航时高亮焦点跟随切换并自动滚动到位
- **PDF 预览** - 内置 PDF 预览器，支持页面渲染和缩放
- **批量管理** - 批量选择后一键批量 OCR / 批量移动 / 批量删除，删除同步清理 OCR 内容与搜索索引
- **批量导入** - 支持一次选择多个 PDF 导入，重名文件自动跳过并提示
- **统一设置** - 设置入口为左栏 ⚙ 按钮，弹窗式左页签卡片（通用 / 模型 / 关于）；存储、PDF 阅读器、OCR 设置（图像尺寸、图像预处理）归入「通用」，模型状态与下载指引归入「模型」，「关于」页展示功能简介、当前版本与版本更新日期
- **模型管理** - 「模型」页可查看各模型套件的下载状态与文件清单、下载网站与存放位置指引，并可启用/停用模型
- **数据目录** - 可在设置中切换数据目录，切换时自动迁移现有数据（重启生效）
- **外部阅读器** - 支持配置外部 PDF 阅读器打开文件
- **OCR 统计** - 文件夹级别显示已识别文档数 / 总文档数
- **可调节布局** - 左中右三栏布局可自由调节宽度
- **Windows 优先** - 当前打包目标为 Windows（NSIS）；后端为 Rust，具备跨平台潜力
- **高性能** - Rust 后端，内存占用低，响应速度快

## 安装

从 [Releases](https://github.com/AchatesRay/PDF-Manager-Tauri/releases) 页面下载安装包。

也可从 GitHub Actions 构建产物中下载 `pdf-manager-win-x64.zip`（解压即可运行，不含 OCR 模型）。

### OCR 模型

首次使用时，程序会自动检测 OCR 模型：

- PDF 列表顶部会显示模型状态（`✓ 模型已就绪` / `✗ 模型未安装`），点击状态文字即可刷新检测
- 模型未安装时会弹出下载对话框，可选择「在线下载」或「手动下载」
- 也可打开 设置 → 模型 页，查看模型下载网站、备用镜像与模型文件存放位置的详细指引

模型文件（PP-OCRv5 Mobile，需成套放入 `models` 目录，文件名保持原样）：

- `pp-ocrv5_mobile_det.onnx` - 文字检测模型
- `pp-ocrv5_mobile_rec.onnx` - 文字识别模型
- `ppocrv5_dict.txt` - 字符字典

## 使用方法

### 1. 创建文件夹

首次使用时，先在左侧面板创建一个文件夹来分类管理 PDF 文件；创建时可为文件夹指定自定义存储目录。

### 2. 导入 PDF

选中文件夹后，点击"添加"按钮导入 PDF 文件：
- 支持一次选择多个文件批量导入
- 重名或重复导入的文件会自动跳过，并在导入结果中提示

### 3. OCR 识别

对于扫描版 PDF：
- 点击 PDF 列表中的"OCR"按钮开始识别
- 任务按顺序排队处理，列表中显示实时进度，可随时取消
- 重启程序后，仍在排队的任务会自动继续执行
- 识别完成后即可搜索内容

### 4. 搜索

在顶部搜索框输入关键词：
- 支持**内容搜索**：在 OCR 识别结果中搜索
- 支持**文件名搜索**：按文件名查找 PDF
- 点击搜索结果可直接跳转到对应页面
- **预览高亮**：内容搜索命中后，右侧预览页上会画出命中位置的高亮框（当前命中为橙色焦点），
  用结果面板的「上一个 / 下一个」导航时高亮焦点跟随切换，跨页跳转、缩放均自动贴合；
  清除搜索即隐藏高亮

> 注意：高亮依赖 OCR 时保存的文字坐标。此前识别过的旧文档若没有坐标，
> 对该文档再点一次「OCR」重新识别后即可获得高亮（搜索本身不受影响）。

### 5. 预览 PDF

点击 PDF 文件，右侧面板将显示预览：
- 支持页面缩放
- 支持翻页浏览
- 可配置外部阅读器打开

### 6. 删除 PDF

单个删除或「批量管理」中勾选后批量删除：
- 删除前弹出确认框
- 删除会**一并清理**：PDF 文件、OCR 识别内容、全文搜索索引、缩略图与队列记录
- 删除后左侧列表与搜索结果面板同步刷新，已删文档的命中不再残留

## 数据存储

默认存储在应用程序所在目录，可在 设置 → 通用 → 数据目录 中切换（切换时自动迁移现有数据，重启生效）：

- `pdf-manager.db` - SQLite 数据库
- `pdfs/` - PDF 文件存储
- `index/` - 搜索索引
- `thumbnails/` - 页面缩略图
- `models/` - OCR 模型文件
- `logs/` - 日志文件

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端框架 | Svelte 4 + TypeScript |
| 构建工具 | Vite 5 |
| 桌面框架 | Tauri 2.0 |
| 后端语言 | Rust |
| 数据库 | SQLite (rusqlite) |
| 搜索引擎 | Tantivy + jieba-rs |
| PDF 处理 | lopdf, pdf-extract, pdfium |
| OCR 引擎 | PP-OCRv5 Mobile (ONNX Runtime / oar-ocr) |
