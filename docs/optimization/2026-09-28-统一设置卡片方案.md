# 方案：统一设置卡片（左页签弹窗 + 关于页）（2026-09-28 已确认）

> 状态：**设计已确认，待执行**。
>
> 用户已拍板的三个决策：
> 1. **页签 3 个：`通用` / `模型` / `关于`** —— 存储设置、PDF 阅读器、OCR 设置**全部并入「通用」页**（用户原话「OCR也放入通用」）；
> 2. **版本更新日期来源 = 前端常量映射表**（`about.ts`，零后端改动）；
> 3. **`✓ 模型已就绪` 状态文字保留**在 PdfList 头部（它是状态指示，不是设置入口）。

## 一、需求理解

1. 模型配置、存储设置、OCR 设置（含 PDF 阅读器）**合并进同一个卡片**；
2. **删除「模型配置」按钮**（`PdfList` 头部），所有设置统一从 **设置按钮**（`FolderTree` 头部 ⚙）进入；
3. 设置按钮点开一个**居中弹窗卡片**，卡片内部**按内容分页签，页签在左侧竖排**；
4. 新增**「关于」页签**：程序功能简介、当前版本、版本更新日期、说明等。

### 现状问题

- 设置分散两处：`SettingsPanel`（内联在左栏）+ `ModelManagerPanel`（独立弹层），交互形态不一致；
- 无「关于」页，版本/更新日期无处展示。

### 现状入口对照

| 入口 | 文件 | 打开内容 |
|---|---|---|
| ⚙ 设置 | `src/lib/components/FolderTree.svelte:217` | `SettingsPanel.svelte`（内联，存储/PDF阅读器/OCR 三段） |
| 模型配置 | `src/lib/components/PdfList.svelte:387-397` | `ModelManagerPanel.svelte`（弹层，经 `stores` 的 `showModelPanel`，由 `OcrModelSetup.svelte:136` 挂载） |

## 二、目标交互

```
┌─────────────────────────────────────────────────┐
│  设置                                     [✕]  │
├────────────┬────────────────────────────────────┤
│  通用      │                                    │
│  模型      │        当前页签内容                │
│  关于      │        （右侧独立滚动）            │
│            │                                    │
└────────────┴────────────────────────────────────┘
   左侧页签        右侧内容区
```

- 弹窗：`position: fixed` 遮罩 + 居中卡片，宽 `min(92vw, 780px)`、高 `max-height: 85vh`；
- 左侧页签栏约 130px，竖排；选中态用现有 `--accent` / `--accent-soft` 变量；
- 关闭方式：✕ 按钮、点击遮罩、`Esc`；
- 复用现有视觉语言（CSS 变量、圆角、字号与 `ModelManagerPanel` 一致）。

### 页签划分（已确认：3 个）

| 页签 | 内容 | 来源 |
|---|---|---|
| **通用** | 数据目录（选择/重置）、日志目录、PDF 阅读器（选择/清除）、OCR 最大图像尺寸、OCR 图像预处理模式 | `SettingsPanel.svelte` **整体**（存储 + 阅读器 + OCR 三段，内容不动） |
| **模型** | 模型下载指引、模型卡片清单、启用/禁用、手动刷新 | `ModelManagerPanel` 整体内容（脱掉自身弹层壳） |
| **关于** | 功能简介、当前版本、版本更新日期、技术栈与说明、致谢/链接 | **新增** |

**「通用」页内部**沿用 `SettingsPanel` 现有的分节标题（`存储设置` / `PDF阅读器` / `OCR 设置`）+ 分隔线，页内仍可滚动 —— 内容零迁移，只换容器。

#### 1. `src/lib/components/SettingsDialog.svelte`（新，核心）

弹窗外壳 + 左侧页签栏 + 「关于」页签内容；「通用」「模型」两页复用现有组件：

```svelte
<script lang="ts">
  import { showSettings, settingsTab } from '../stores';   // SettingsTab = 'general' | 'model' | 'about'
  import SettingsPanel from './SettingsPanel.svelte';         // 通用页（存储+阅读器+OCR，内容不动）
  import ModelManagerPanel from './ModelManagerPanel.svelte'; // 模型页（内容化后）
  import { RELEASES, APP_FEATURES, APP_NOTES, APP_LINKS } from '../about';
  import { getVersion } from '@tauri-apps/api/app';

  let version = '';
  onMount(async () => { try { version = await getVersion(); } catch { version = '1.1.0'; } });
  $: releaseDate = RELEASES[version] ?? '—';
  // Esc 关闭、遮罩点击关闭、✕ 关闭
</script>

{#if $showSettings}
  <div class="overlay" on:click={close}>
    <div class="dialog" role="dialog" on:click|stopPropagation>
      <div class="dialog-header"><h4>设置</h4><button class="close-x">✕</button></div>
      <div class="dialog-body">              <!-- display:flex -->
        <nav class="tab-rail">               <!-- 左侧竖排页签 -->
          <button class:active={$settingsTab==='general'}>通用</button>
          <button class:active={$settingsTab==='model'}>模型</button>
          <button class:active={$settingsTab==='about'}>关于</button>
        </nav>
        <div class="tab-content">            <!-- flex:1; overflow-y:auto -->
          {#if $settingsTab === 'general'}   <SettingsPanel />
          {:else if $settingsTab === 'model'} <ModelManagerPanel active />
          {:else} ...关于页内容（见下）
          {/if}
        </div>
      </div>
    </div>
  </div>
{/if}
```

「关于」页签内容：

- **应用**：PDF Manager
- **功能简介**（要点）：本地 PDF 文档管理（文件夹树分类、导入/移动/批量管理）；扫描件中文 OCR（识别队列、进度、多模型切换）；中文全文搜索 + 文件名搜索，命中结果预览高亮；内置预览 / 外部阅读器打开。
- **当前版本**：`getVersion()`（`@tauri-apps/api/app`，读 `tauri.conf.json` → 当前 `1.1.0`，**纯前端、不改后端**）。
- **版本更新日期**：查 `about.ts` 的 `RELEASES[version]`。
- **说明**：技术栈 Tauri 2 / Rust / Svelte 4；数据全部本地存储，不上传；OCR 模型来自 oar-ocr（PP-OCRv5），PDF 渲染基于 pdfium；附模型下载页 / 项目链接（可点开、可复制）。
