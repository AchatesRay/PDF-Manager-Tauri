# PDF Manager UI 重新设计 - 方案A：精致极简

**日期：** 2026-03-20
**状态：** 已实现

## 设计概述

基于用户需求（简约专业 + 优化现有布局 + 专业文档管理），采用精致极简设计风格，打造高端文档工具的专业感。

## 设计理念

### 视觉风格
- **配色：** 纯净的奶白背景 + 深灰文字 + 克制的蓝色强调
- **字体：** IBM Plex Sans（英文）+ Noto Sans SC（中文）
- **空间：** 增加留白，减少视觉拥挤
- **边框：** 1px 浅灰分割线，微妙的阴影层次

### 核心原则
1. **克制**：避免过度装饰，功能优先
2. **精致**：关注细节，微妙的交互反馈
3. **专业**：适合长时间使用的文档管理场景
4. **清晰**：明确的视觉层次和信息分组

## 组件设计

### 1. 布局结构 (AppA.svelte)
- 三栏布局保持不变
- CSS 变量定义主题色彩
- 可拖拽调整面板宽度
- 响应式适配

### 2. 文件夹树 (FolderTreeA.svelte)
- 简洁的列表项设计
- 圆角 8px 的选中态
- 浅蓝色高亮激活项
- 文件夹图标使用 SVG
- 数量徽章样式优化

### 3. 搜索栏 (SearchBarA.svelte)
- 下拉选择器 + 输入框 + 搜索按钮
- 聚焦时蓝色边框 + 浅蓝阴影
- 搜索图标按钮化设计
- 清除按钮仅在搜索结果时显示

### 4. PDF 列表 (PdfListA.svelte)
- 卡片式列表项
- 圆角 8px 边框
- 选中态：蓝色边框 + 浅蓝背景
- 状态指示：彩色圆点 + 文字
- 操作按钮：OCR（绿色）、删除（悬停红色）

### 5. 搜索结果 (SearchResultsA.svelte)
- 顶部固定结果统计和导航
- 关键词导航按钮
- 结果项：文件名 + 页码徽章 + 匹配数 + 摘要
- 高亮关键词：黄色背景
- 当前匹配：橙色背景 + 白色文字

### 6. PDF 预览 (PdfViewerA.svelte)
- 深灰色背景（#374151）
- 工具栏：深色主题
- 白色 PDF 页面预览
- 阴影效果增强层次感

## 交互设计

### 悬停效果
- 列表项：浅灰背景
- 按钮：颜色加深或背景变化
- 图标按钮：浅蓝色背景

### 选中状态
- 文件夹：浅蓝背景 + 蓝色文字/图标
- PDF项：蓝色边框 + 浅蓝背景
- 搜索结果：蓝色左边框 + 浅蓝背景

### 加载状态
- 旋转加载指示器
- 禁用按钮灰色显示

## 功能保留

所有原有功能均已保留：
- 文件夹管理（创建/删除/树形结构）
- PDF 管理（添加/删除/列表筛选）
- 全文搜索（内容/文件名）
- 关键词导航和匹配切换
- OCR 处理和状态显示
- PDF 页面预览和缩放
- 设置面板

## 实现说明

1. 使用 CSS 变量实现主题一致性
2. SVG 图标替代 emoji，更专业
3. 过渡动画使用 0.15s ease，响应迅速但不突兀
4. 响应式字体大小适配不同内容
5. 滚动区域优化，避免内容溢出
